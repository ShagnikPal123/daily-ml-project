# daily-ml-project

A new small, working machine learning project every day. Each project lives in its own dated folder with its own README, code and a quick way to run it.

**Areas covered:** computer vision · audio · NLP and LLM tooling · quant analysis (historical data only, no live trading) · assorted ML and tech experiments.

## Conventions

- Folder name: a short descriptive kebab-case name (the date lives in the index table)
- Every project has a README with what it does, how to run it, and what it showed
- Only synthetic or openly licensed data; no API keys or secrets committed
